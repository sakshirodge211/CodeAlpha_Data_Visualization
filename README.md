# CodeAlpha Task 3 - Data Visualization

## Project Overview

This project is completed as part of the CodeAlpha Data Analytics Internship.

The objective of this task is to create meaningful visualizations from a dataset of 1,000 books collected from the Books to Scrape website.

The visualizations help understand book prices, ratings, and the most expensive books in the dataset.

## Dataset

The dataset contains 1,000 book records collected from Books to Scrape.

The main columns include:

- Title
- Price
- Rating
- Availability
- Product_URL

## Technologies Used

- Python
- Pandas
- Matplotlib

## Visualizations Created

### 1. Top 10 Expensive Books

`top_10_expensive_books.png`

This chart shows the 10 books with the highest prices in the dataset.

### 2. Book Rating Distribution

`book_rating_distribution.png`

This chart shows the number of books available for each rating from 1 to 5 stars.

### 3. Book Price Distribution

`book_price_distribution.png`

This chart shows how book prices are distributed across the dataset.

### 4. Average Price by Rating

`average_price_rating.png`

This chart compares the average book price for each rating category.

## Key Findings

- Total books analyzed: **1,000**
- Book prices range from **£10.00 to £59.99**
- The highest-priced books are around **£60**
- The dataset contains ratings from **1 to 5 stars**
- The visualizations help identify price and rating patterns in the dataset

## Conclusion

The project demonstrates how Python and Matplotlib can be used to transform raw data into clear and meaningful visualizations.

These visualizations make it easier to understand patterns in book prices and ratings and communicate data-driven insights.
